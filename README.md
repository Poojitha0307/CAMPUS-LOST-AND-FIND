
# CampusConnect – Campus Lost-and-Found Mobile Application

## 📱 Project Overview

CampusConnect is a mobile application designed to help students report lost and found items within a college campus. Users can submit item details, upload images, and view available lost and found reports.

## PROJECT LINK:
https://www.figma.com/make/OGrwwqNw0xOijGY1eZ2ZQB/CampusFind-mobile-app-design?fullscreen=1&t=zviM4IMu9j6cpiSu-1&code-node-id=0-6

## 🎯 Objectives

* Report lost items.
* Report found items.
* Upload or capture item images.
* View lost and found item details.
* Use Android Intents and Services.
* Implement multithreading for better performance.

## ✨ Key Features

* Lost Item Reporting
* Found Item Reporting
* Image Capture and Gallery Selection
* Item List Display
* Android Intents
* Background Service
* Multithreading

## 🔄 Application Workflow

```text
Launch App
    ↓
Home Screen
    ↓
Report Lost / Found Item
    ↓
Enter Item Details
    ↓
Capture / Select Image
    ↓
Validate Details
    ↓
Save Data in Background
    ↓
View Item List
```

## 🧵 Performance Optimization

Multithreading is used to perform data processing in the background, keeping the user interface responsive and preventing the application from freezing.
